# Міжнародні документи та перевірка якості

Стан: 12 жовтня 2026. Це початкове дослідження джерел і відтворюваний діагностичний тест, а не перевірка всіх архівів світу. Каталог джерел не означає, що всі його документи завантажені, розпізнані або доступні для навчання.

## Що вже перевіряється

Локальні документи користувача: рукописні метричні таблиці, розвороти, бліді рукописи, суцільний текст, друковані шематизми, PDF із текстовим шаром та PDF зі сканами. Результати й приватні транскрипції залишаються в ігнорованій Git папці `test-output/`. Успішний запуск OCR не є підтвердженням правильності прочитання.

[HTR-United](https://htr-united.github.io/) надає метадані наборів із перевіреними транскрипціями. Завантажений каталог містить 138 наборів. Команда `scripts/catalog_htr.py` зберігає кількість наборів за мовою, письмо, період, формат та заявлену ліцензію. Це аналіз метаданих; умови потрібно звіряти з оригінальним набором, бо навіть назва ліцензії та її URL іноді суперечать одне одному.

[EHRI Dataset — FloChiff](https://github.com/FloChiff/ehri-dataset) містить машинописні документи чеською, данською, англійською, німецькою, угорською, польською та словацькою з ALTO-транскрипціями. Заявлена ліцензія CC BY 4.0. Документи походять із різних установ; мова документа не визначає країну його зберігання. Посилання на установи та правила транскрипції наведені в README джерела.

Наш тест бере лексикографічно першу сторінку кожної мовної підпапки без відбору за результатом. Версія джерела закріплена: `20a5e002031c1f9e66176133b4602ed439db6521`. Перевіряються Git blob-хеші, записуються SHA-256 зображень, еталонів і моделі. Зображення та еталони не додаються до репозиторію ArchiveReader.

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/benchmark_ehri.py --fetch
.\.venv\Scripts\python.exe -X utf8 scripts/benchmark_ehri.py
```

Результат: `test-output/ehri/report.json`. CER/WER обчислюються після Unicode NFC і згортання пробілів; регістр, діакритика та пунктуація зберігаються. Це оцінка всього процесу: пошук рядків, порядок читання та розпізнавання. Деякі рукописні доповнення й закреслення виключені з еталонів EHRI, тому зайвий текст OCR теж збільшує помилку. Одна сторінка на мову не дозволяє оцінити мову загалом. Перетин із даними попереднього навчання базової моделі невідомий. У цьому проєкті модель на цих сторінках не навчали.

## Початкова карта офіційних джерел

У тесті EHRI використовується порядок рядків ALTO. На чеському зразку він місцями відрізняється від візуального порядку сторінки, що завищує помилку порівняння цілих текстів. Ці числа не варто трактувати як чисту точність рушія. Для порівняння читання використовується окремий [тест однакових рукописних рядків](HTR_COMPARISON.uk.md).

Нижче перевірені сторінки установ або документація сервісів. Статус усіх порталів у цій таблиці — **джерело знайдено; окремий імпортер і OCR-корпус порталу ще не перевірено**. Локальні файли з FamilySearch не означають перевірку інтеграції із сайтом.

Поточний скрипт EHRI завантажує лише 14 файлів даних і список версії; масового сканера сайтів у програмі немає.

## Як розширювати корпус

Окремо враховувати країну установи, місце створення, мови, письмо, період, жанр, геометрію сторінки й пошкодження. Серед потрібних класів: метричні таблиці різних конфесій; змішані книги; переписи; нотаріальні акти; судові справи; листування; друкована готика; машинопис; газети; карти; форми з рукописними вставками; правобічне й вертикальне письмо.

Для кожного зразка потрібні стабільне посилання, шифр/сторінка, права, SHA-256, мови, тип письма, опис структури, перевірений еталон (або явна відсутність еталона) та роль train/validation/test. Сторінки однієї справи й дублікати не можна розділяти між навчанням і незалежним тестом. Відомий почерк бажано відокремлювати за писарем.

Перегляд нових документів розширює вимоги й тести, але сам собою не навчає OCR-модель. До покращення точності ведуть перевірені виправлення, окреме навчання та повторне порівняння на відкладених документах. Універсальної точності для всіх країн, століть і систем письма ця версія не обіцяє.
