# Установка Windows

Збірка пакета з вихідного проєкту: `powershell -File scripts/Package-Windows.ps1`. ZIP з’являється в `dist`; вихідний код, документи проєкту й зібрана програма включені, а приватні бібліотеки, скани, ваги моделей і віртуальне середовище — ні.

Розпакуйте ZIP і запустіть `Install-ArchiveReader.cmd`. Установник копіює програму в `%LOCALAPPDATA%/Programs/ArchiveReader`, установлює Python-залежності й створює ярлик на робочому столі. Потрібні Python із pip та .NET 10 Windows Desktop Runtime; перевірки виконуються до запуску програми. Ця збірка й зафіксовані залежності перевірялися з Python 3.12. Установка залежностей потребує інтернету; TrOCR встановлюється окремо за `requirements-htr.txt`.

Установлена програма зберігає бібліотеку в `%LOCALAPPDATA%/ArchiveReader/data`, окремо від файлів програми. Оновлення не видаляє бібліотеки чи копії. Установка не переносить автоматично бібліотеку вихідного проєкту — для перенесення скористайтеся резервною копією та відновленням. Моделі потрібно вибрати вручну; їхні ваги й приватні дані в ZIP не включені.

Для роботи з вихідним проєктом лишається `Start-ArchiveReader.cmd`: він використовує локальну папку `data` і перебудовує змінений код. Для встановленої копії .NET SDK не потрібен, поки вихідний код не змінюється; потрібен Desktop Runtime. Пакет не є підписаним MSI/MSIX чи повністю автономним установником. Повна установка на чистому іншому комп’ютері ще не перевірена; перевірено складання ZIP, копіювання файлів і запуск зібраної програми на поточному Windows.
